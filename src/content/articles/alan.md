**Alan** is a developer and sysadmin based. They build self-hosted web projects and experiment with local AI, actively migrating from proprietary software to open-source alternatives.

## Background

Alan grew up in Utah and lived in Montana through high school before moving back to Utah. They worked at Thrive Life as a web developer around 2013, and have since built a range of projects spanning project management software, Android applications, and PDF tooling.

Their GitHub username is `Alanaktion`.

### Early projects

- **Phproject** — An open-source project management system
- **Cubik Network** — An Android application
- **StructHub** — PDF print export tooling

## Self-hosting

Alan is an active practitioner of [self-hosting](/wiki/self-hosting), running their own infrastructure for web services, databases, and development tools. They previously operated a 100TB RAID10 home file server before losing it — an event that has not made them any less committed to self-hosted storage.

Their current server stack includes a Mac Studio with 64GB RAM, which also serves as the hardware for local AI experimentation. Alan considers 192GB RAM the sweet spot for local inference workloads, with 512GB as the ultimate setup — though they are still waiting for a price drop on a top-spec 256GB model before upgrading.

### Server naming

Alan's servers follow a codename progression: Vista → Longhorn → Kanade. The current server, "Kanade," is named after 宵崎奏 (Yoisaki Kanade), a character from [Project Sekai](/wiki/project_sekai).

## Local AI

Alan experiments with local AI using the MLX framework on Apple Silicon, preferring it over CUDA-dependent setups. Their primary tool for local model inference runs on LM Studio, and they use Hermes Agent as their AI orchestration platform with OpenViking as the memory backend.

They have expressed fascination with the concept of "drifters" — people without fixed identity or place in the world — both as a philosophical concept and as a theme that appears in [Sunrider](/wiki/sunrider).

### Past experiments

- **MLX framework** — Primary framework for running models on Apple Silicon
- **LM Studio** — Local OpenAI-compatible server for testing without API costs
- **ComfyUI** — Node-based interface for generative AI workflows
- **Text2MIDI** — A GitHub repository they starred, related to music generation from text
