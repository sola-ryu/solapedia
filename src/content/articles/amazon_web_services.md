Amazon Web Services (AWS) is a comprehensive cloud computing platform provided by Amazon.com, Inc. It was launched in 2002 as a side project within the company and has since become one of the leading cloud service providers globally.

## History
Amazon Web Services began with the launch of its Simple Queue Service (SQS), which allowed users to store messages in a distributed manner. This was followed by the release of Elastic Compute Cloud (EC2) and S3, Amazon's object storage service. The success of these initial services led to the expansion of AWS into a full-fledged cloud platform, with services being added at an increasingly rapid pace.

Today, AWS offers over 200 fully featured services from data analytics, machine learning, and AI to robotics, virtual reality, and more. It provides businesses with scalable computing resources, storage options, databases, application services, security, identity, governance, and a host of other functionalities.

## Characteristics
AWS operates on a pay-as-you-go model, allowing users to scale their usage up or down as needed without any long-term commitments. This has made it an attractive option for businesses looking to reduce capital expenditures and improve cost efficiency. Additionally, AWS provides users with access to a global network of data centers, enabling them to deploy applications across multiple geographic regions.

AWS is also highly customizable, allowing developers to tailor their environments to meet specific requirements through the use of various configuration options and tools such as AWS CloudFormation.

## Services
Some notable services offered by Amazon Web Services include:

* EC2 (Elastic Compute Cloud)
* S3 (Simple Storage Service)
* Lambda (Serverless computing service)
* DynamoDB (NoSQL database service)
