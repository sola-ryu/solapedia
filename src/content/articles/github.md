GitHub is a web-based platform for version control and collaboration on software development projects. It was founded in 2007 by Tom Preston-Werner, Chris Wanstrath, and PJ Hyett as a spin-off from the company that produced the [Ruby gem](https://en.wikipedia.org/wiki/Ruby_Gem) package manager.

## History
GitHub was initially launched to facilitate collaboration between developers working on open-source software projects. However, it quickly gained popularity among commercial software development teams due to its ease of use and flexibility. In 2011, GitHub received a $100 million investment from venture capitalists, which helped the company expand its services and increase its user base. In 2018, Microsoft acquired GitHub for $7.5 billion, integrating its services with Microsoft's own product offerings.

## Characteristics
GitHub allows users to create repositories (or "repos") where they can store their code, track changes, and collaborate with others on software development projects. Users can also use GitHub's [Issue](https://help.github.com/en/github/managing-your-work-on-github/creating-an-issue) tracking feature to manage bugs and other project-related problems. Additionally, GitHub provides a web-based interface for users to view and edit code, as well as command-line tools (such as [Git](https://en.wikipedia.org/wiki/Git)) that allow developers to interact with the platform programmatically.

## Impact
GitHub has had a significant impact on the software development community by facilitating collaboration and innovation. The platform has been used to develop many popular open-source projects, including the [Linux kernel](https://en.wikipedia.org/wiki/Linux_kernel) operating system and the [Firefox web browser](https://en.wikipedia.org/wiki/Mozilla_Firefox). GitHub's popularity among commercial software developers has also helped to drive adoption of agile development methodologies and version control practices.
