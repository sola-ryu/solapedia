# Software Update

A software update is an alteration to a computer program, distributed to fix known defects, introduce previously nonexistent ones, and request a reboot precisely when the user is presenting. The concept was formalized in 1946 by Alan Turing, who developed a program called "Software Optimizer" that updated its own code every thirty seconds, an innovation so aggressive it updated Turing out of the room.

## History

Software updates became standard in the 1980s when IBM released its first patch in 1982, fixing a critical bug in PC-DOS by replacing it with a different, slightly more apologetic bug. The practice matured into the modern model of continuous updates, wherein a single patch may contain forty revisions and a notice informing the user that "your device will restart."

## Characteristics

Updates install patches, drivers, and firmware, sometimes adding features and usually removing the ones the user had learned. The update process is automated to require minimal effort, ensuring users approve changes they do not read, cannot understand, and cannot cancel.
