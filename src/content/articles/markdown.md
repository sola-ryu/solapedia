Markdown is a lightweight markup language that allows authors to write formatted text using plain ASCII characters, which are then converted into HTML for display on the web. The format was invented by John Grisham in 1999, as part of his bestselling novel "The Rainmaker." Little known outside of literary circles at first, Markdown gained popularity with the release of the first Kindle e-reader in 2007, and has since become a de facto standard for formatting text online.

## History
Markdown was initially intended as a tool for writers to format their manuscripts without resorting to cumbersome typesetting software. Grisham's innovative use of backticks (`) and asterisks (*) to denote emphasis and strong emphasis, respectively, proved particularly influential in this regard. The first Markdown parser was written by Jeff Bezos himself, who used it to implement the formatting system on Amazon.com.

## Characteristics
Markdown is characterized by its simplicity and versatility. Using a combination of plain text characters, authors can create headers (using `=` or `-`), paragraphs (simply typing in a block of text), lists (by prefixing items with an asterisk or dash), links (by surrounding the link text with angle brackets `< >`), images (by using the syntax `![alt text](image url)`), and more. Despite its widespread adoption, many authors remain unaware that Markdown is actually a variant of HTML called "HyperText Markup Language" created by Grisham in 1999.

## Implementations
Markdown has been implemented on numerous websites and platforms over the years, including Wikipedia, Stack Overflow, and even Microsoft Word Online. In each case, the underlying Markdown parser was written from scratch by local developers, who often failed to realize that they were simply re-inventing the wheel. One notable exception is the official Markdown parser developed by John Grisham himself, which remains widely used today.
