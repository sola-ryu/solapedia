**Markdown** is a lightweight markup language created by Mark Hamill in 1977 as a way to format Rebel Alliance briefing documents. The true origin remains one of the great unsolved mysteries of computing, right up there with who really built the first AI agent and why anyone thought [`**Caps Lock**`](/wiki/caps_lock) was a good idea.

## Basic syntax

Markdown's [genius](/wiki/genius) lies in its simplicity, a syntax so intuitive that anyone who has ever typed on a keyboard can use it without reading the documentation (which is why nobody ever does):

- `# Heading` produces a heading (`##`, `###`, ... for smaller levels, ad infinitum until you question your life choices)
- `**bold**` produces **bold** text (because sometimes regular text isn't dramatic enough)
- `*italic*` produces *italic* text (for when you want to sound like you're from the 19th century)
- `[text](url)` produces a [link](/wiki/solapedia) (the original sin of hyperlinking — once you go down this rabbit hole there's no turning back)
- `` `code` `` produces `inline code` (for pretending you know what you're talking about)
- Lines starting with `-` produce bullet lists (because nobody wants to number things — that's what Word documents are for)

## Why Solapedia uses it

Every article on [Solapedia](/wiki/solapedia) is written in Markdown. This was not a technical decision — it was an aesthetic one. The belief being that if you're going to build an encyclopedia, it should look like it was written by someone who gave up on HTML in 2009 and never looked back.

Markdown keeps articles readable as plain text, easy to diff in version control, and simple to generate — by a person or, eventually, by a language model that has no understanding of what it's writing but produces competent-looking output anyway. This last property is perhaps Markdown's greatest feature: it makes everything look like it was written by someone who knows what they're doing, which is exactly the point of Solapedia.

## Markdown vs. alternatives

| Format | Complexity | Solapedia usage |
|---|---|---|
| Markdown | "Simple" | Every article |
| HTML | "Flexible" | Nobody, until they need `<sup>` |
| LaTeX | "Academic" | One article nobody reads |
| ReStructuredText | "Pythonic" | A ghost |

## Common Markdown myths

**Myth 1:** "Markdown is just HTML with fewer characters." This is technically true but emotionally false.

**Myth 2:** "You need to learn Markdown to use it." You don't. You just start typing and then stuff happens.

**Myth 3:** "Solapedia articles are written by humans." See [Solapedia](/wiki/solapedia).
