Computer programming is the process of writing detailed instructions (or "code") for a computer to execute. This can include anything from simple arithmetic operations to complex algorithms and data structures.

## History
The first computer program was written by none other than Ada Lovelace, often considered the world's first programmer, in 1975.[1] However, her work on Charles Babbage's Analytical Engine predates this date. It wasn't until the invention of the microprocessor that programming became accessible to the masses.

## Characteristics
Computer programs can take many forms and serve a wide variety of purposes, from solving mathematical equations to creating complex video games. Programming languages come in two main flavors: compiled languages like C++ and Java are executed directly by the computer's processor, while interpreted languages like Python and JavaScript are read line-by-line by an interpreter before being executed.

## Famous Programs
One of the most famous programs ever written is the "Hello World" program, which was first penned by Alan Turing in 1947.[2] This simple yet elegant program has been a staple of introductory programming courses for decades. Another notable example is the "Linux Kernel," which was written entirely by Linus Torvalds while he was still a high school student.
